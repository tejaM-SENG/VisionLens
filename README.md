# VisionLens – Photography Website

A modern, multi-page photography website featuring a premium dark theme, elegant gold accents, and a visually rich browsing experience.

## 📌 Overview

VisionLens is a photography-themed website designed to showcase photography services and present visual content through an elegant, luxury-inspired interface.

The website uses a dark color palette with gold accents to create a sophisticated visual identity. It includes 10+ pages with consistent navigation, structured layouts, and responsive styling.

## ✨ Features

- **Premium UI Design:** Dark theme with elegant gold accents.
- **Multi-Page Layout:** More than 10 pages with consistent styling.
- **Photography Presentation:** Visually focused layouts for showcasing photography.
- **Responsive Design:** Layouts designed for desktop, tablet, and mobile screens.
- **Navigation:** Consistent navigation across website pages.
- **Reusable Styling:** Common design patterns and components throughout the website.
- **Modern Typography:** Carefully styled headings, text, and visual sections.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5


## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/tejaM-SENG/VisionLens
```

### 2. Navigate to the Project

```bash
cd VisionLens
```

### 3. Run the Website

Open the main HTML file in your browser.

You can also use the **Live Server** extension in Visual Studio Code for local development.
